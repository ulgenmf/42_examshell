Unary operator- Cluster: same symbol as lesson 4's binary minus, different parameter count, different rule

Source: vect2 main, -v2.

Contrast: unary - vs. binary - (lesson 4) -v2 has one operand. v1 - v1 has two. Both use the token -. C++ treats these as two entirely separate operator overloads, distinguished purely by parameter count — declaring one does not declare the other.
Slot: declaration, inside the class, zero parameters vect2 operator-() const; Rule: zero explicit parameters — the single operand is the object the function is called on, implicitly. Returns a new vect2 with both components negated. const because negating does not modify the original (-v2 must leave v2 unchanged).

What you write

Add operator-() (no parameters) to vect2.hpp/.cpp, alongside the two-parameter operator- from lesson 4. Recompile through std::cout << "-v2: " << -v2.
