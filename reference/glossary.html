Terms — construction

constructor

A function with the same name as the class, no return type, that runs exactly once when an object of that class is created. Lesson: 1.

default constructor

A constructor taking zero arguments. Slot: Type name;. The compiler generates one automatically only if the class declares no constructors of its own. Lesson: 1.

direct-initialization

Constructing an object with arguments in parentheses directly after the variable name: Type name(args);. Lesson: 1.

copy-initialization

Constructing an object using = at the point of declaration: Type name = existing;. This calls a constructor, not operator=, because name does not exist yet at the point = is written. Lesson: 1.

copy constructor

A constructor whose single parameter is a reference to an existing object of the same class. Duplicates the existing object's member values into the new object. Reachable from both direct-initialization and copy-initialization syntax — one function, two call slots. Lesson: 1.

Terms — functions and operators

member function

A function declared inside a class body. Called either as object.name(args), or implicitly through operator syntax like x[i] or x + y when the operator is declared as a member. The left-hand object of an operator call is received implicitly, not as an explicit parameter. Lessons: 2, 4.

free function

A function declared outside any class. For an operator, this means both operands are explicit parameters — required whenever the left operand's type cannot have a member function added to it (a built-in type, or a type like std::ostream that you did not write). Lessons: 3, 4.

reference

An alternate name for an existing variable, not a copy of it. Declared with &. Used as a parameter type to avoid copying (const Type&), and as a return type to hand back the actual object rather than a copy (Type&) — required for chained assignment/compound-assignment expressions. Lessons: 2, 6.

Terms — const

const (on a variable)

Slot: const Type name(...);. The variable cannot be reassigned after construction, and only functions marked const (see below) may be called on it. Lesson: 9.

const (on a reference parameter)

Slot: (const Type& name). The function promises not to modify what the reference refers to; required to accept const arguments. Lesson: 9.

const (on a member function)

Slot: ReturnType name(...) const; — the keyword appears after the parameter list. Promises the function does not modify the object it is called on. Required for a member function to be callable on a const object at all. Lesson: 9.

Terms — copying and lifetime

copy assignment operator

The overload of operator= invoked when assigning to an object that already exists: existing = other;. Distinct from copy-initialization (which constructs a new object and never calls this function). Returns a reference to *this. Lesson: 10.

destructor

Slot: ~Type();. Runs automatically when an object's lifetime ends. No parameters, no return type, one per class. Lesson: 10.

orthodox canonical form

42-specific term (not standard C++ terminology — the closest standard equivalent is the "Rule of Three"). A class declaring all four of: default constructor, copy constructor, copy assignment operator, destructor. Required explicitly by polyset's subject text. Lesson: 10.

Terms — inheritance (polyset)

base class

The class named after the colon in a derived class's declaration: class Derived : public Base { ... };. Its non-private members become available inside Derived. Lesson: 11.

pure virtual function

Slot: virtual ReturnType name(...) = 0;. Declares that the function must exist in any concrete (constructible) derived class, but provides no implementation itself. A class with at least one unimplemented pure virtual function is abstract and cannot be constructed directly. Lesson: 11.

override

Slot: ReturnType name(...) override;, written in a derived class. Not required by the language, but should always be present — it makes the compiler check that this function actually matches a virtual function declared in a base class. Lesson: 11.

base class constructor call

Slot: Derived::Derived(args) : Base(args) { }, the colon appearing after the parameter list, before the function body. Specifies which base class constructor runs before the derived class's own constructor body. Lesson: 11.
